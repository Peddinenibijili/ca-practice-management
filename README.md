# CA Practice Management Platform

Original Turia-inspired CA/CS practice management starter application.

## Stack
- Backend: Node.js + Express + PostgreSQL
- Frontend: React + Vite
- Authentication: JWT
- Local development: Docker Compose

## Included
- Login/register
- Multi-organization foundation
- Dashboard
- Clients CRUD
- Tasks CRUD
- Employees/attendance foundation
- Documents metadata foundation
- GST / Income Tax / Tax Audit / PAN / Project Report service categories
- PostgreSQL schema and seed data
- Docker Compose

## Quick start

1. Copy `.env.example` to `.env` in `backend`.
2. Run:
   `docker compose up --build`
3. Open:
   `http://localhost:5173`
4. API:
   `http://localhost:5000/api/health`

Default demo login:
- Email: admin@example.com
- Password: Admin@123
